# 文档索引（cursor-tts）

本仓库文档以「规范驱动实现」为准。编码前请先读计划中的当前任务，并以契约为工具合同。

## 阅读顺序（推荐）

1. [功能设计](design/TTS播报功能设计.md) — 做什么、不做什么、进展触发原则  
2. [技术架构](design/TTS播报技术架构设计.md) — 怎么分层、选型、演进  
3. [MCP 工具契约](spec/MCP工具契约.md) — **实现合同**（speak/stop）  
4. [P1 服务 API](spec/P1服务API.md) — 本地 HTTP 服务  
5. [Cursor 接入与配置](guide/Cursor接入与配置说明.md) — 注册、配置、User Rule、日志  
6. [开发计划](plan/开发计划与任务拆分.md) — T1–T7 与 DoD  
7. [Hook 调研结论](plan/Hook调研结论.md) — T7：本期不做自动播报 Hook  
8. [验收用例](qa/验收用例.md) — D/B 分级验收  

冲突时优先级：**契约 > 架构 > 功能设计**；接入/验收与契约冲突时以契约为准并回改文档。
