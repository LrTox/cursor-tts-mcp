## 1. 目标与范围

### 1.1 P0 目标

交付可用的 `cursor-tts` MCP：`speak`/`stop` 符合契约；进展触发可验收；edge-tts + SAPI 降级可用。

### 1.2 P1 目标

抽出本机 TTS 服务（队列 + stop）；MCP 变薄客户端；日志可观测。Hook **调研后可选，非必做**。

### 1.3 本计划不包含

付费云 TTS、语音输入闭环、自研模型、macOS Helper、默认全文朗读、未调研强行实现的 Hook。

### 3.3 任务完成定义（DoD）

每个任务完成须同时满足：

1. 行为符合 [MCP工具契约](../spec/MCP工具契约.md) v1.3+
2. 目录符合技术架构模块边界（无反向依赖）
3. 相关验收用例通过或标注「阻塞原因」；行为抽查允许有限复测
4. 无临时测试脚本残留（用后即删）；正式测试进 `tests/`
5. 不擅自扩大范围（云 TTS、全文朗读、未调研 Hook 硬做等）
6. **P0 起**：引擎名/失败原因输出到 **stderr**（见接入说明 §7.1）

## 4. 实现顺序规范（防乱生成代码）

代码生成/手写时必须按层推进，禁止一次堆出无边界大文件。

| 顺序 | 允许新增 | 禁止 |
|------|----------|------|
| 1 | 包结构、`models`、`config`（分音色）、空 `server` | 先写云厂商、先写 Hook |
| 2 | `text_policy`、假 Player 单测 | 跳过契约字段；混用 edge/sapi voice |
| 3 | `SapiEngine` + 真 Player | 尚无 stop 就加复杂队列 UI |
| 4 | `EdgeTtsEngine` + router | 改工具名/响应字段语义 |
| 5 | orchestrator：队列、interrupt 清队列、去重 | 默认开启全文朗读 |
| 6 | README/接入实测 | 未验收就拆 P1 |

### 4.1 文件落地约定

- 先建目录与空模块，再填实现（与项目规则一致）
- 配置键名与环境变量以接入文档为准，不得另起一套
- 工具 description 文本与契约第 3.1 / 4.1 节保持一致

## 6. 风险与缓冲

| 风险 | 缓解 | 缓冲 |
|------|------|------|
| edge 网络不稳 | 先 T2 SAPI 保底可演示 | T3 +0.5d |
| 播放进程杀不干净 | 统一子进程模型；T2 重点测 stop | T2 +0.5d |
| Agent 不按进展调用 | User Rule + AC-PRG 抽查/复测，不挡确定性门禁 | T5 复测 |
| P1 双实例双播 | 禁止 MCP 内嵌回退播放 | T6 专项 |
| Cursor Hook 不可用 | T7 跳过 Hook，只交付日志 | 无 |
